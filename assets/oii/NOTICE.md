# Attribuzione dell’icona

L’icona di Olinfo Trainer Companion adatta il marchio grafico delle Olimpiadi Italiane di Informatica. Il [file originale](https://github.com/olimpiadi-informatica/website/blob/52fe0773d44672d3dfcc52b5a7134cac7344b14e/static/logos/oii.png) è pubblicato nel repository del sito ufficiale, con il [testo della licenza MIT](https://github.com/olimpiadi-informatica/website/blob/52fe0773d44672d3dfcc52b5a7134cac7344b14e/LICENSE) incluso anche qui.

La versione per VS Code è stata adattata con ImageGen. La versione JetBrains è una riproduzione vettoriale semplificata dell’icona adattata. Il progetto è indipendente dalle OII.

## Prompt ImageGen

> Create a square extension icon using only the green O and the ivory and red vertical i letters of the exact OII logo at the far left in the reference image. The graphic is an official OII mark used as a visual element for an independent competitive programming IDE companion. Delete the wide wordmark on the right entirely. Keep the OII silhouette, Italian green/ivory/red colors, and the small inner circuit-board details recognizable. Place the mark centered inside a single solid dark navy rounded-square tile, with generous margins and transparent corners. Add only one subtle pair of small pale code angle brackets framing the mark, if they remain distinguishable at 40 pixels. Flat, sharp vector-style contours in a few solid colors, with no gradient, texture, shadows, white margins, or extra text. The whole tile is square and reads clearly at small extension icon sizes.
